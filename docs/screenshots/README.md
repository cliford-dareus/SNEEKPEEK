# Screenshots

Add PNG/JPG captures here and reference them from the root `README.md`.

Suggested filenames (already linked in the main README):

- `home.png` — main feed / dashboard
- `profile.png` — user profile
- `messages.png` — conversations or chat view

Optional extras:

- `login.png`
- `register.png`
- `requests.png`

Tips:

1. Capture from the [live demo](https://sneekpeek.netlify.app) or local `npm run dev`.
2. Prefer ~1280px width; keep file size under ~500KB each.
3. After adding files, the main README image table will display them automatically.
